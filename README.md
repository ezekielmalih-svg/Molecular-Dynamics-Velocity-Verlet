# Molecular Dynamics with Velocity Verlet

This project explores classical molecular dynamics using Python, with a focus on numerical integration of particle motion using the Velocity Verlet algorithm.

The notebook was developed as part of my coursework in the Erasmus Mundus Master's programme in Theoretical Chemistry and Computational Modelling (TCCM).

## Topics Covered

- Classical molecular dynamics
- Velocity Verlet integration algorithm
- Harmonic potential
- Morse potential
- Double-well potential
- Symbolic calculation of forces
- Position and velocity propagation
- Potential and kinetic energy calculations
- Total energy analysis
- Visualization of molecular dynamics trajectories
- Extension to two-dimensional molecular dynamics

## Tools

- Python
- NumPy
- SymPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Notebook

The main notebook is:

`MD_VVERLET_Student.ipynb`

It contains the implementation of the Velocity Verlet algorithm, simulations using different model potentials, analysis of the resulting trajectories and energies, and graphical visualization of the dynamics.

## Context

This work was completed as a computational physical chemistry coursework project. The original project framework was provided through the pyPhysChem teaching materials, while the calculations, simulations, and exercises presented in the completed notebook were carried out as part of my coursework.
